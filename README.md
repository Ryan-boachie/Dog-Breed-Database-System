# Dog-Breed-Database-System
Database-driven management system designed for Green Futures focusing on conservational education, dog breed awareness, and responsible ownership initiative. 
Dog Breed Awareness Management System

## Overview

This is a database-driven management system designed for an educational organization focused on dog breed awareness and responsible ownership initiatives.

This project was developed as part of a systems analysis and database design assignment and demonstrates the complete process of designing a relational database system capable of managing members, staff, educational workshops, bookings, payments, attendance, and feedback records.

The project was creatively adapted from the original Green Futures case study while still following the core database and system design requirements outlined in the assignment brief.

---

## Project Objectives

The aim of the system was to design a centralized solution capable of:

- Managing member information

- Managing staff records

- Organizing educational workshops and awareness events

- Supporting project and workshop bookings

- Tracking participation and attendance

- Recording payments and member feedback

- Improving operational efficiency through structured data management

---

## Features

### Membership Management

- Basic, Silver, and Gold membership levels

- Member profile management

- Booking limitations based on membership level

### Workshop & Project Management

- Dog breed awareness workshops

- Responsible ownership education sessions

- Community awareness events

- Workshop scheduling and management

### Booking System

- Search available workshops

- Book educational projects/events

- View booking records

- Track participation

### Payments & Feedback

- Store payment records

- Track workshop fees

- Collect member feedback and ratings
